## Notes

- **AGPL-3.0**: the whole OrcaPad work, including OrcaSlicer-derived
  code and the OrcaPad Bridge, is licensed under the GNU AGPL v3.0
  ([LICENSE](LICENSE)).
- **ADMesh (GPL-2.0-or-later), CGAL core (GPL-3.0-or-later)**:
  one-way compatible — conveyed as part of the AGPL-3.0 combined
  work, exactly as upstream OrcaSlicer distributes them.
- **libnoise / NLopt 2.5.0 (LGPL-2.1+) and libnest2d (LGPL-3.0)**:
  statically linked. Compliance mirrors upstream OrcaSlicer's own
  distribution model: the complete combined-work source — including
  these libraries and the full build system — is conveyed at no charge
  for every release, enabling any recipient to rebuild and relink
  (LGPLv3 §4(a); LGPLv2.1 §6's relinking purpose served by the
  full-source rebuild path; see COMPLIANCE.md §W4).
- **OrcaPad Bridge**: adapter and shim sources are OrcaPad-authored
  (AGPL); no upstream TBB, OpenSSL, or OCCT code is distributed.
- **Host headers** (boost 1.90, Eigen 3, CGAL 6, GMP, MPFR): the
  engine compiles against system headers symlinked into the build;
  their sources are vendored into the release source archive under
  `host-headers/` with a version manifest, so the archive is
  self-contained Corresponding Source.
- **Header-only** rows enter the binary through `#include`; their
  license evidence files ship in the full source archive.
- The complete corresponding source of every release is attached to
  its GitHub Release as `OrcaPad-<version>-full-source.tar.gz`.
