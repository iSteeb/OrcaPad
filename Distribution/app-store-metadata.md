# App Store / TestFlight listing metadata (COMPLIANCE.md W6)

Template for the App Store Connect listing (description and support text)
and the TestFlight beta metadata. Review on every release (checklist in
COMPLIANCE.md §5). The description must state the license, the source
location, and the upstream attribution — and must not imply proprietary
restrictions (no "all rights reserved", no IAP).

## App description (App Store Connect → OrcaPad → Description)

```
OrcaPad brings a native 3D-printing slicer to iPadOS: import a model,
arrange it, pick printer and print settings, slice, inspect the toolpath,
and send the G-code to your printer — with the slicing engine of OrcaSlicer
running entirely on your device.

OrcaPad is free, open-source software licensed under the GNU Affero General
Public License v3.0. The complete source code of this app — including the
exact version you are running — is published at
https://github.com/iSteeb/OrcaPad (see About & Licenses inside the app).

OrcaPad contains and modifies OrcaSlicer (© SoftFever and contributors),
which is based on Bambu Studio, PrusaSlicer, and Slic3r. OrcaPad is an
independent community project and is not affiliated with or endorsed by
them. Full third-party license information is bundled in the app
(About & Licenses).

Report issues: https://github.com/iSteeb/OrcaPad/issues
```

## Rules for future edits of this listing

- Keep the license sentence, the source URL, and the attribution paragraph
  in every revision of the description.
- The app stays gratis; no in-app purchases, no paywalled functionality
  (COMPLIANCE.md W8).
- Do not describe the app with proprietary-sounding claims ("all rights
  reserved", "unauthorized copying prohibited", …).
- Beta App Review sees the TestFlight "What to Test" notes generated by CI
  from the tag message and commit log — keep tag messages user-appropriate.
